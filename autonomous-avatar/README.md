# 自律で動く女性アバター (autonomous-avatar)

女性アバターが完全に自律的(ユーザー操作なし)に歩いたり、走ったり、考えたり、喜んだりする様子を
ただ眺めるだけのWebページです。

## 使い方

`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
npx serve autonomous-avatar
```

## 設計方針(条件との対応)

- **実装が簡単**: ビルド不要のvanilla JS + CSS。スプライトシートの表示位置を切り替えるだけでアニメーションを実現しており、3Dエンジンや外部フレームワークへの依存がありません。
- **商用利用が可能**: アバター素材は [Kenney](https://kenney.nl/) の「[Toon Characters 1](https://kenney.nl/assets/toon-characters-1)」(CC0 / パブリックドメイン)。商用利用・改変・帰属表示なしで利用できます(全文: `assets/LICENSE-kenney-toon-characters-1.txt`)。
- **拡張性**: `js/avatar.js` の行動選択(`ACTIONS`)は重み付きテーブルなので、新しい仕草(スプライトシートには `attack0-2` `climb0-1` `hang` `slide` `kick` など未使用フレームが多数収録済み)を足すだけで挙動を増やせます。`js/scene-objects.js` は独立モジュールなので、蝶や鳥以外の背景演出も自由に追加できます。
- **将来のゲーム化の余地**: 同じCC0スプライトシートのまま、[Phaser](https://phaser.io/) などの2Dゲームエンジンに移植して当たり判定・スコア・複数キャラクターの追加が可能です。Kenneyは背景タイルやアイテムなど同系統の無料素材群(CC0)も豊富に公開しているため、将来アセットを揃える際も同じライセンス方針のまま拡張できます。

## 使っている素材とライセンス

- **アバター**: Kenney「Toon Characters 1」の "Female adventurer" スプライトシート(`assets/character_femaleAdventurer_sheet.png`)。CC0(パブリックドメイン)。歩行(`walk0`〜`walk7`)・走行(`run0`〜`run2`)・ジャンプ・考え中(`think`)・会話(`talk`)・喜び(`cheer0`/`cheer1`)は、いずれも素材に収録済みの実フレームをそのまま切り替えて再生しているだけで、自作の関節モーションは使用していません。フレーム座標は同梱の `assets/character_femaleAdventurer_sheet.xml` を参照しています。
- **空・雲・太陽・草原・蝶や鳥**: すべてCSS/絵文字による自作表現で、外部素材は使用していません。

## 構成(モジュール分割)

- `index.html` — ページ構造
- `style.css` — 見た目・スプライト表示・雲や太陽のアニメーション
- `assets/` — Kenneyのスプライトシート本体・フレーム定義・ライセンス全文
- `js/avatar.js` — アバターの行動選択(重み付き乱数)と、状態(歩く/走る/ジャンプ/考える/話す/喜ぶ/待機)に応じたスプライト切り替え。ユーザー入力は一切扱いません
- `js/scene-objects.js` — 蝶や鳥など、背景で自律的に動く演出オブジェクト
- `js/main.js` — 上記モジュールを組み立てて画面に接続する起点

## 操作方法

ありません。ページを開くと自動でアバターが動き始め、時間経過とともに行動をランダムに変えていきます。
