# ここにVRMファイルを配置してください

`avatar.vrm` という名前でこのフォルダに置くと、自律アバターとして読み込まれます。

## 使用する想定のモデル

VRoid公式サンプル **AvatarSample_A**(商用利用可・クレジット表記不要)を想定しています。

1. https://hub.vroid.com/en/characters/2843975675147313744/models/5644550979324015604 を開く
2. VRoid Hub(pixiv)アカウントでログインし、VRM形式でダウンロード
3. ダウンロードしたファイルを `avatar.vrm` にリネームしてこのフォルダに配置

配置されるまでの間は、代わりに簡易プレースホルダー(ピンク色のカプセル型人形)が表示されます。
