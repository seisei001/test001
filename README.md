# URLリンク内容ビューア

URLが1行ずつ書かれたテキストファイルを読み込み、順番にそのページの内容を表示して、必要な部分を編集してリストに追加し、最後にまとめて1つのテキストファイルとしてダウンロードできるWebアプリです。

## 使い方

1. 依存パッケージをインストール

   ```bash
   npm install
   ```

2. サーバーを起動

   ```bash
   npm start
   ```

3. ブラウザで `http://localhost:3000` を開く

4. 画面上で「テキストファイルを選択」から `sample-urls.txt` のようなURLリストファイル(1行に1URL)を読み込むか、「直接貼り付け」でURLを貼り付けて「読み込み開始」を押す

5. 1件ずつページの本文が表示されるので、必要な部分だけ残すように編集し、「この内容をリストに追加」を押す(不要なページは「追加せず次へ」でスキップ)

6. 全件確認し終えたら「まとめてダウンロード」で保存済みの内容を1つのテキストファイルとしてダウンロードできる

## 仕組み

- ブラウザから直接他サイトを`fetch`するとCORSで失敗することが多いため、サーバー側(`/api/fetch`)で対象URLを取得し、`cheerio`でHTMLから本文テキストを抽出してからブラウザに返しています。
- 読み込んだURLリストや保存済みの内容は`localStorage`に保存されるため、ページを再読み込みしても続きから再開できます。
