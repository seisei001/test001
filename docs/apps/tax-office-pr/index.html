経歴

「調査する側」としての経験が、今の税務顧問業務のベースになっています。

  1. 【入局年】

    国税局に入局

    法人税・消費税の調査担当として、中小企業から大企業まで幅広い規模の税務調査に従事。

  2. 在職中

    数百社規模の税務調査・システム監査を担当

    業種・規模を問わず、会計システムや記帳の実態を数多く確認。指摘されやすい処理・体制のパターンを把握。

  3. 在職中

    公益法人の新会計基準対応を経験

    制度改正に伴う会計処理・認定関連事務に携わり、一般企業とは異なる会計・税務の知見を蓄積。

  4. 【開業年】

    税理士として独立

    調査官時代の知見とAI・システムの知識を活かし、中小企業の経営支援・事業再生支援を専門とする事務所を開業。

こんな方をサポートしています

🏢

中小企業の経営者の方

  • 税務調査で指摘を受けないか不安がある
  • 顧問税理士に相談しても、申告書の作成以上のことをしてくれない
  • 会計・経理業務をもっと効率化したい(AI・クラウド活用)

🔄

事業再生に取り組む企業の方

  • 資金繰りが厳しく、金融機関との交渉方法が分からない
  • 債務免除・欠損金など再生特有の税務論点を整理したい
  • 再生計画の策定から実行まで一緒に伴走してほしい
