AIを税務実務に統合できる技術者

Transformerや重み行列などAIの構造を研究者レベルで理解。現在、複数のAIプロバイダを横断利用できる 会話ログ×RAG基盤「raglog」(開発中・コンセプト)を構築している。

  • Gemini・Claude・ChatGPTを横断利用できるプロバイダ抽象化層(providers.py)
  • Gemini Embeddingsによるベクトル化 + コサイン類似度によるセマンティック検索(embeddings.py / similarity.py)
  • 長文の自動チャンキング(chunking.py)、URLからの本文抽出(webfetch.py)
  • Flask + SQLiteによる会話エントリ・設定管理(app.py / db.py / settings.py)

将来的には条文ベースのRAGなど、税務実務への応用を目指している。

🤖 Claude(Anthropic)による評価

坂口誠が執筆した論文「複雑系における影響関係と安定構造 ― ランダムweightsを実験媒体とした状態軌跡の研究」を、 Claudeが実在の引用文献を検証したうえで評価しました。以下はAIによる技術評価であり、事務所自身の主張ではありません。

本稿が引用するHe・Wang・Hopcroft(2016, NeurIPS)、Ramanujanら(2020, CVPR)、Berlyand・Krupchytskyi・Slavin (2026, Networks and Heterogeneous Media)は、いずれも実在し、内容も正確に要約されている。学習前のランダムな 重みからも非自明な構造(固定点・高性能な部分ネットワークなど)が生まれるという、現在進行形の専門文献を正しく 踏まえた研究設計になっており、一般論ではなく技術的な理解に裏付けられている。

一方で本稿は、実験結果を伴わない研究提案・エッセイの段階にある。後半で「意味」「粒子」「距離」「時間」 「エネルギー」を影響関係から導こうとする議論は、現時点の科学で裏付けられた主張ではなく思弁的な仮説として 読むべきである。また、固定点・安定性というテーマに直結するPooleら(2016)の平均場理論(order-to-chaos転移) など、関連度の高い先行研究への言及がない点も指摘しておきたい。

総合すると、ニューラルネットワークの重みの構造に関する技術的理解は、正確な文献理解に裏付けられたレベルに あると評価する。ただし本稿全体は「査読済みの研究成果」ではなく、「今後検証すべき仮説を提示する研究ノート」 として位置づけるのが適切である。

誠

税理士

坂口 誠

昭和61年4月1日、大阪国税局に入庁。中小企業の税務調査、国税局大型コンピュータのプログラマー・システムエンジニア、 システム監査手法を用いた大規模法人調査、国際税務調査、査察部国際専門官などを歴任。国税局在籍時には、 消費税における「固有法人」(公益法人等)の申告実務にも携わる。令和5年7月10日に退職し、税理士登録。 2026年10月1日、兵庫県神戸市に坂口誠税理士事務所を開業。

税理士登録後は、公益法人の申請承認・新会計基準への移行に関する事務にも対応。査察部による捜査(査察)を 受けた案件では不起訴という形で立件を阻止し、他二社を含む通常の税務調査については、対応した案件すべてが 申告是認となっている。

※査察(捜査)と税務調査(行政調査)は法的根拠も性質も異なるため、「申告是認」は通常の税務調査についての 実績、「不起訴」は査察についての実績として、分けて記載しています。

近年はAI領域にも取り組み、Transformerや重み行列などの構造について研究者レベルの理解を持つ。現在、 Gemini・Claude・ChatGPTを横断利用できる会話ログ×RAG基盤「raglog」(開発中)を構築しており、 将来的には条文ベースのRAGなど、税務実務への応用も目指している。詳しくは「坂口誠の専門性」の項をご覧ください。
