# 森の塊の描き方(R1)の再生手順
いつでも同じ絵を作り直せるようにした記録(2026-11-21)。道具は forest_mass.py の1本。

## 必要なもの
- Python3 と numpy・Pillow・OpenCV(cv2)。実行は `python3 -I forest_mass.py <出力png> <種> <型>`(種は省略時3)。
- 広葉樹の影絵見本(第2版用): mapstyle/gv/stamps/broad_00〜08.png(現在の第3版以降の方式では使わない)。
- 同じ種なら同じ絵になる(第9版・第10版で確認)。

## 方式(ユーザー指示 11-21)
1. 暗い深緑の下地(端は不規則)。第10版以降は、なめらかな乱数の高さの地図+中心が高い丘で形を決める(関数 blob_mask_gauss)。
2. 暗い層: 縁の帯(幅約14%)は「上の木」、中は「下の三日月」を、下地の約70%を覆うまでランダムに置く。
3. 明るい層: ガウス揺らぎの場で置く確率を決める(関数 make_mix の light_gauss)。目標の被覆率は約22%。
4. 広葉樹(丸い樹冠+上の三日月)と針葉樹(2段の三角+光側の尖り三角)は別々の部品(broad3_tile / conif3_tile)。
5. 塊の絵は SS=3 の拡大描きから縮める。色は PAL(広葉樹 broad3・針葉樹 conif)。

## 型と版の対応(コマンド例。出力は例)
| 版 | 型 | コマンド | 内容 |
|---|---|---|---|
| 第3版 | (なし) | `python3 -I forest_mass.py out.png 3` | 丸い樹冠+上下の三日月 |
| 第5版 | mix | `... out.png 3 mix` | 下地→縁は上の木→中は下の三日月 |
| 第6版 | lowlight | `... out.png 3 lowlight` | 明るい層を下側約45%だけ |
| 第7版 | dome | `... out.png 3 dome` | 明るい層の上の境目を丸く持ち上げ |
| 第8版 | gauss | `... out.png 3 gauss` | 明るい層をガウス揺らぎで(広葉樹) |
| 第9版 | conif | `... out.png 3 conif` | 針葉樹を同じ方式で(広葉樹と並べる) |
| 第10版 | gbase | `... out.png 3 gbase` | 下地の形もガウス揺らぎ(種0〜2×広葉樹・針葉樹) |
※ 第1・2版(単純な影絵)は、関数 make(...) の kind='broad'(影絵見本)/既定の三角で再生できる。

## 主な調整値(初期値。関数の引数)
- make_mix: tree_px(木の大きさ)、band_frac=0.14(縁の帯)、cov_in/cov_edge(暗い層70/60%)、kind_in/kind_edge(中/縁の木の種類。針葉樹は conif3_moon/conif3_top)、light_gauss={'seed','sigma'=0.11,'k'=1.8,'bias'=0.5,'cov'=0.22}、base_gauss={'seed','sigma'=0.07,'k'=0.75}(第10版)。
- blob_mask_gauss: 面積を約40%にそろえる・穴をふさぐ・最大の1塊だけ残す。
- 実寸(世界地図用): 塊の大きさ100、木の幅 広葉樹4.0〜8.4。
