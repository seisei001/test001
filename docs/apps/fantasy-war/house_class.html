家クラスの詳細設計(案)

概要: 街や村の「でき方」と「家そのもの」を切り分ける。家はクラス(間取りが元データ、部品はそのメンバ)として作り、外観はそこから導く。ローポリを先に作ると無駄になるので、ここは形でなく構造の設計。すべて私の案(未確定)。

1. 切り分け(4つの層)

層役割この設計の対象か
A 集落の構成街・村の「でき方」。どこに何の家を建てるか別の設計。家へは「注文書」だけ渡す
B 家クラス家1軒の構造(等級・間取り・部品)今の詳細設計の対象
C 見せ方地図では記号。画面に映す時だけ配置して描く(物の背後は記号に戻す)別の設計(n-symbol)。必要な時だけ配置
D 家の内部家の中に入れる層。作るかどうかも未定別の層。ただしBの間取りを元データに使える形にしておく

2. 集落の構成(Aの層・参考の整理だけ)

街(大きな街): 中心に大きな家。その周りに中くらいの家。比較的整然とした区画で、碁盤の目に近い建ち方が多い。区画が変わると、やや小さく安っぽい建物群に変わる。
村: 大きな家の周りを、少し小さな家が比較的丸く取り囲む。碁盤の区画の村は存在しない。地形に合わせて建つ。密集した村も、バラバラの村もある。
→ 家の側では「街らしさ」を考えない。街・村のパターンは別に設計し、実際の配置は見せる必要がある時だけ行う。

AからBへ渡す「家の注文書」

項目内容
位置・向き敷地の中の場所と正面の向き(Aが決める)
等級大・中・小・安(Aが決める。街の中心=大、周り=中、区画外れ=小・安、村=大の周りに小〜中)
用途住居・店・工房・館 など
敷地幅・奥行き(家と付属が収まる大きさ)
地方・年代材質の組を決める(同じ集落は同じ地方)

3. 家クラス(B)の構造

House(家)
├ 属性: 等級・用途・地方・年代・向き・敷地
├ Plan(間取り) ← 元データ。升目(1升=長さ3.9m×奥行4.9m)の上に部屋を置く
│ ├ Room(部屋): 升の範囲・階・機能(広間・台所・寝室・私室・貯蔵・玄関・階段・店・作業)・炉の有無
│ └ Opening(開口): 戸・窓(細/二連/低/大)・店の開口。壁のどの位置か
├ Parts(部品=クラスのメンバ) ← 間取りから導く(下の規則)
│ 土台・壁・階の箱・張り出し・屋根・煙突・窓一式・戸一式・ポーチ・差し掛け・出窓・階段塔 など
└ Looks(体裁): 材質・屋根材・色の微妙なばらつき(幅は小さく)

間取りから部品を導く規則(案)

間取りにあるもの導かれる部品
外周の升の境壁(材質は地方の組)。凹凸があれば翼・屋根が別に生える
階の数階の箱。木骨なら上階の張り出し、石造なら帯石
炉のある部屋煙突(炉の数だけ。位置はその部屋の上)
台所小窓+差し掛け小屋(裏、等級が中以上なら)
広間大きな窓(多連)
玄関(戸のある升)戸一式(扉・枠・踏み石)。必要ならポーチ
階段(等級が大)階段塔(2m角の塔と角錐屋根)。それ以外は内部の階段で外には出ない
店広い開口+庇
寝室・私室・貯蔵機能に応じた窓の数・大きさ

効果: 部品の置き方がそのまま間取り図になる。家の中に入る層(D)を作る時は、同じ間取りから内部を作れる。作らない場合でも、クラスは家の体裁を持つ。

4. 等級と、家の型(間取りのパターン)

等級目安使われ方(Aの層で決める)
安1室・1階。小屋のような家区画外れ・貧しい群
小1〜2室村の外側・街の外縁
中3〜4室・1〜2階。広間+台所+寝室街の周り・村の主
大多室・2〜3階・翼・階段塔街の中心・村の大きな家

下の間取りは、家の型の案(7種)。ばらつき(升の数・向き・開口の位置・付属・材質・色)は、型の中で小さく動かす。図は間取りのデータから描いている。左が1階、右が2階。◆=炉、赤=戸、青=窓、橙=店の開口。

5. 未決(あなたの判断が要る点)

  1. 1升の大きさ(3.9m×4.9m)と、等級4段階(大・中・小・安)でよいか。
  2. 間取りは「部屋の機能」まで持つ(内部の層に渡せる)形でよいか。
  3. 型7種の過不足(例: 馬小屋・農家の納屋つき・宿屋 など)。

限界: 英国の広間型・箱型の知識に偏る。階段塔は大きな家だけに限定した。外観の細部(貼り絵・色)は未設計。1升の寸法や部屋の数は、実物の寸法を調べて直す前提の仮置き。
