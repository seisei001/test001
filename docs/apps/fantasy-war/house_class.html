家クラスの詳細設計(案)

概要(改訂 11-28): 家はクラス。間取りは「長方形のブロック+つながり(廊下もブロック)」を元データとし、型(約50種)と等級(序列)で作り分ける。部品はそこから導く。屋敷の回廊・塔も、新しい部品でなく等級で付く。ここは形でなく構造の設計。すべて私の案(未確定)。

1. 切り分け(4つの層)

層役割この設計の対象か
A 集落の構成街・村の「でき方」。どこに何の家を建てるか別の設計。家へは「注文書」だけ渡す
B 家クラス家1軒の構造(等級・間取り・部品)今の詳細設計の対象
C 見せ方地図では記号。画面に映す時だけ配置して描く(物の背後は記号に戻す)別の設計(n-symbol)。必要な時だけ配置
D 家の内部家の中に入れる層。作るかどうかも未定別の層。ただしBの間取りを元データに使える形にしておく

2. 集落の構成(Aの層・参考の整理だけ)

街(大きな街): 中心に大きな家。その周りに中くらいの家。比較的整然とした区画で、碁盤の目に近い建ち方が多い。区画が変わると、やや小さく安っぽい建物群に変わる。
村: 大きな家の周りを、少し小さな家が比較的丸く取り囲む。碁盤の区画の村は存在しない。地形に合わせて建つ。密集した村も、バラバラの村もある。
→ 家の側では「街らしさ」を考えない。街・村のパターンは別に設計し、実際の配置は見せる必要がある時だけ行う。

AからBへ渡す「家の注文書」

項目内容
位置・向き敷地の中の場所と正面の向き(Aが決める)
等級序列の値(Aが決める。街の中心=高い、周り=中、区画外れ=低い。村=高い家の周りに中〜低)。段階の数はA層の設計で決める(未決)
用途住居・店・工房・館 など
敷地家と付属が収まる大きさ(ユニット数で表す)
地方・年代材質の組を決める(同じ集落は同じ地方)

3. 家クラス(B)の構造(改訂)

House(家)
├ 属性: 等級(序列の値)・用途・地方・年代・向き・敷地
├ Pattern(間取りの型) ← 構造の軸から出した約50種(下の一覧)
├ Plan(間取り) ← 元データ。型を選び、等級で大きさと付属を決めて作る
│ ├ Block(ブロック): 長方形・平面の位置と大きさ・階の範囲(高さ)・機能(広間・台所・寝室・貯蔵・店・玄関・階段・廊下など)
│ └ Link(つながり): ブロックとブロックを結ぶ戸・通路。廊下もブロック(回廊=中庭を囲むブロックのつながり、塔=背の高いブロック)
├ Parts(部品=クラスのメンバ) ← 間取りから導く(下の規則)
└ Looks(体裁): 材質・屋根材・色の微妙なばらつき(幅は小さく)

1ユニット(ブロックの基準寸法)は、その土地の計り方で決め、部品はそれに合わせて作る(ユーザー確定 11-28)。ここでは寸法を数字にせず、1ユニット=1升と呼ぶ。実物の計り方は別に調べる。

間取りから部品を導く規則(案)

間取りにあるもの導かれる部品
ブロックの外周壁(材質は地方の組)。凹凸があれば翼・屋根が別に生える
ブロックの階の範囲階の箱。木骨なら上階の張り出し、石造なら帯石。背の高いブロックは塔
炉のあるブロック煙突(炉の数だけ。そのブロックの上)
台所小窓+差し掛け小屋(等級が上なら)
広間大きな窓(多連)
玄関(戸のあるつながり)戸一式(扉・枠・踏み石)。必要ならポーチ
廊下・回廊のブロック低い屋根(差し掛け)・柱列。中庭を囲めば回廊
店広い開口+庇

効果: 部品の置き方がそのまま間取り図になる。家の中に入る層(D)を作る時は、同じ間取りから内部を作れる。

4. 等級と、間取りの型(約50種)

等級は、「許すブロック数・階数・付属(差し掛け・ポーチ・翼・回廊・塔)の幅」と「材質の格」を決める序列の値。屋敷のような巨大な建物も、新しい部品は要らず、等級が上がるだけで回廊や塔がつく。段階の数は、街・村の構成(A層)が必要とする区別から決める(未決)。それまでは序列の値のまま持つ。
型(パターン)の出し方: 間取りの形は無限にあるが、費用をかけず約50のパターンで持つ。軸の掛け算で出す。
軸1 並べ方(8): 一列・L字・T字・コ字・H字・口字(中庭)・並列(2棟を廊下で結ぶ)・奥行き二重
軸2 つなぎ方(形ごとに違う): なし(部屋が直接つながる)・通り抜け(玄関の通路)・片廊下・中廊下・回廊
軸3 階の構成(3): 平屋・一部だけ2階・全部2階
塔・吹き抜けは型に含めず、等級で付く部品(背の高いブロック)にする。

図は型の骨組み(ブロックとつながり)。濃い色=2階あり、灰色=廊下、点=つながり。同じ型でも、ブロックの大きさ・向き・機能・開口は小さく動かして個体差を出す。つながりの数は図からの自動集計(目安。廊下との接点も数える)。

機能をつけた間取りの例(旧案の型7種は例示で、型の全体ではない)

5. 未決(あなたの判断が要る点)

  1. 型の軸(並べ方8・つなぎ方・階の構成3)に過不足がないか。51種で足りるか。
  2. 等級の段階数は、街・村の構成(A層)を設計する時に、必要な区別から決めてよいか。

限界: 英国の広間型・箱型の知識に偏る。1ユニットの寸法は未決(土地の計り方を調べて決める)。型の図は骨組みだけで、機能・開口は旧案の例にだけある。外観の細部(貼り絵・色)は未設計。
