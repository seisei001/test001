間取りの学習ノート

2026-11-28 作成。ユーザーの指示「家屋の間取りをちゃんと勉強してね」への学習結果。確定=ユーザーが決めたこと / 案=Claudeの整理(要確認) / 無印=資料にあった事実。資料は要約経由で、平面図は見ていない。

概要(まず3行)

  • 間取りで最も重要なのは利便性。ただし何が便利かは、自然・生業・社会・構造の4つの入力で決まる。確定(利便性)案(4入力の整理)
  • 間取りは「必要な機能の集合」を「ゾーンに分け」「つながり」を決めて「外形」に収めたもの。形の分類ではない。案
  • 家のあり方は、上位(自然条件)から下位(部品)へ導いて書く。確定

1. ユーザーが決めたこと(11-28 05:26)確定

  • 間取りで最も重要な要素は利便性。太陽の位置も大きな理由。
  • 都市は山の端で水のある所にできる。南斜面。庭は南に作る。向きの問題は太陽が理由。
  • 屋根は降水量の問題。
  • 地震の多い日本は岩造りに合わず、簡単に壊れる軽い家を作る文化(自然との融合)。
  • 砂漠の民は木がないので粘土を材料にした。粘土の家は平屋が中心。焼きレンガで家を作る土地は砂漠化する。岩の家は岩を産出する地域特有の様式。地域性。
  • 多角的な観点から、家のあり方を上位から下位に向けて書く。シミュレーターである前に、その作りがClaudeやプログラムに向いている。

※原文の「年度」は「粘土」と読んだ(要確認)。「南=日が当たる側」は北半球の話。

2. 間取りを決める4つの入力案

入力中身平面・形への出方(資料の例)
自然日・雨・雪・風・地震・水と地形・産する材料乾燥地=厚い土壁と中庭 / 湿地=高床と通風 / 豪雪=太い柱梁で背が高い / 地震=軽い木造と礎石 / 冬の風=屋敷林
生業農・漁・牧・養蚕・酒造・商い土間・庭先・納屋・牛馬屋 / 馬屋付きのL字(曲り屋・中門造) / 屋根裏の多層利用(養蚕) / 番屋 / 町家の店
社会家族・身分・習俗・宗教・防衛座敷・蔵・離れ・格式で使い分ける出入口 / 中庭式の表(客)と奥(家族) / 曲がって見通せない入口 / 核家族を前提にした51C型
構造柱と梁の枠・材料の寸法梁間の枠を足して桁行へ増築(最多) / 畳の寸法(約90×180cm) / 1間(低地ドイツは約2.5m)

3. 上位から下位への導出の階段案

  1. 目的: 利便性(暮らしやすさ)
  2. 入力: 自然・生業・社会・構造(上の表)
  3. 立地: 山の端・水辺・南斜面
  4. 向きと配置: 南向き・庭は南・開口は南(北半球)
  5. 構造と材料: 地震が多い→軽い木造 / 木がない→粘土→平屋 / 石の産地→石造 / 焼きレンガ→燃料の木を使い森が減る
  6. 屋根: 降水量で勾配と軒の出が決まる
  7. 間取り: 利便性(動線・ゾーン・隣接)を外形に収める。機能の集合は生業と社会で決まる
  8. 部品: 機能から導く

下位で分かったことが上位を変えさせる往復は、これまでのルールどおり残す(変えるときは理由と日付を記録)。

4. 日本の民家
  • 基本: 土間(作業・調理)と床上(暮らし)が並ぶ。土間が建物の半分を超える家もある。
  • 型の変遷: 広間型三間取り → 食違い四間取り(広間を南北に仕切る・中期) → 整形四間取り=田の字型(江戸後期・最多)。広間型は、広間が中央、下手に土間、上手に客間「出居」と寝室「納戸」。17世紀後半〜18世紀初頭の中堅農民・庄屋の家。「田の字が最古」という通説は戦後の研究で覆り、広間型のほうが古い。
  • 増やし方: 仕切り直すより外へ足す。①土間側へ ②土間だけ前へ ③床上を背面へ ④桁行方向に部屋を足す(最多)。理由は、梁間の枠を増やして間をつなぐ架構だから。案構造の枠が増築の向きを決める。
  • 身分と敷地: 地主300坪以上・自作200坪・小作100坪(摂津市の例)。地主は田の字に1列足して3続きにし、蔵と離れ座敷が付く。農家に共通の機能=庭先(干す場)・納屋・牛馬屋。
  • 生業・気候の反映: 馬屋付きL字=曲り屋・中門造(東北) / 養蚕=屋根裏を多層に使う(兜造・合掌造) / 漁=番屋 / 酒造・藍=専用の棟 / 豪雪=柱梁が太く背が高い / 風=屋敷林 / 防火=町家の漆喰・土蔵造 / 材料は地元調達(松・茅)。
  • 町家: 間口が狭く奥へ続く。土間は側面の通り道に縮小。二階建て。店の奥に居室が3列並ぶ例もある。
  • 分棟型(九州): 土間と居室を別棟にして結ぶ。
  • 日本の特徴(世界の比較資料より): 畳が基準寸法、紙の可動間仕切り、縁側、礎石の上に柱(地震で石が個別に動く)。
5. 世界の家
型特徴理由・背景
中庭式(アラブ・中国・韓国)中庭を囲む口の字。外壁は高く窓は小さい。入口は曲がり見通せない。開口は中庭へ向く。表は客、奥は家族。仮説=高温乾燥・視線の遮断・密集・宗教法。原因は未解明。
乾燥地の設計(米国)厚さ約40cmの土壁(蓄熱)。L字/コ字で寝室を中庭に向ける。公は道側。深い庇。二階建て密集は壁を共有して外気に触れる面を減らす。日射と温度の調整。
粘土の家(北アフリカ・中東)厚約50cmの未焼成の壁。ヤシの梁。屋根に粘土。密集した多層(イエメンは8階)。格子窓。石の基礎。肥えた土地を残すため密集して建てる。熱の安定。
高床(河・湖・海辺)床を上げ、通風と湿気を逃がす。増水・湿気・漁との近さ。
遊牧のテント分割の布で男女を分ける。煙が入口に来ない向きに立てる。移動。
トルコのソファ型廊下を作らず、中心の広間に各個室が直接つながる。遊牧のテントの集まりが起源。廊下型の対極。
英国のホールハウス機能が一列に並ぶ核。広間が中央、一端がサービス(貯蔵・食糧庫、通り抜けの通路)、反対端が客間・私室。台所は後に裏の別棟へ。ウィールド型は4間の原型で、広間が吹き抜け、両端間の上に私室。16〜17世紀に床と暖炉を入れて吹き抜けが終わる。足し方=床を入れる・翼・裏へ・上へ・差し掛け。
英国の大邸宅中庭型。門楼・前庭(馬屋・納屋)・長い廊下(ギャラリー)。広間と私室(プリヴィ)が分離。身分と防衛。
低地ドイツ型ホールハウス1間約2.5m、2〜10間。妻側の大扉→中央の土間通路(ディーレ)→両脇に家畜小屋→奥に炉・台所→居住部。人と家畜が同居。英国と入口の向きが違う(英=側面の通り抜け、独=妻の大扉)。
6. 現代の間取り
  • 手順: 要望(必要な機能)→ゾーニング→動線→敷地に収める。
  • ゾーン: 公(LDK・玄関)/私(寝室・子供室)/水回り。二世帯は親・子・共用。階をまたぐ(垂直)と同じ階(水平)がある。
  • 動線: 家事・生活・来客の3種。来客動線は私の空間と分ける。家事を優先し、水回りを集約。回遊できれば廊下が短い。
  • 型: 賃貸2LDKでも、居室とリビングが半分ずつ並ぶ型・リビング全幅の型・寝室を前に置く型・横並び型・上下2階の型の5型ほど。違いは同じ部屋群の並べ方だけ。
  • 歴史: 西山夘三の食寝分離論 → 1951年の51C型(約35平米・台所を広くして食事と寝る場を分ける=DKの始まり・襖で仕切る) → 公団の2DK・3DK → 1964年に3LDKの表記。核家族が前提。51CがnLDKの原型かは研究者で意見が分かれる。
  • 自動生成の研究: 間取り=部屋(長方形が大半)の集まり。入力は①外形 ②部屋の種類とつながりの図(バブルダイアグラム) ③途中までの間取り。

7. 本質(私の理解)案

  • 間取り = 機能の集合 + ゾーン + 隣接・行き来の関係 + 外形。長方形の部屋と廊下のつながり、というユーザーの捉え方と同じ抽象。
  • 古今東西の家は、同じ構造で「機能の集合」と「外形の伸び方」が違う。機能の集合は生業と社会が、外形と材料は自然と構造が決める。
  • これまでの私の「並べ方8種」は外形の分類だけを見ていて、上位(自然→地域)が抜けていた。
  • 等級は、機能の多さ(大きな家ほど回廊・離れ・別棟の台所が加わる)で決められそう。「4」には根拠がなかった。

8. 限界・未確認

  • 資料の大半は、要約を介して読んだ。平面図そのものは見ていない。寸法の数値は少ない(低地ドイツの約2.5m、畳、壁厚程度)。
  • 未学習: 中国の合院、地中海の石造、東南アジア、欧州大陸の石造・木骨、アフリカの円形住居。
  • 未読: 庶民の家(英国)・中部ドイツ型・ウィキのテューダー建築(取得制限)。日本の間取りの歴史の学術論文(筑波大のPDFなど)。
  • 世界データ(気候・降水・気流)に、地震・材料の産地・日照があるかは未確認。
  • 「南が日当たり」は北半球のみ。ファンタジー世界で南半球や別の太陽の動きがある場合は別に決める。
