PWGの使い方 ― 端に陸が出る問題の検証(2026-11-20)

概要: PWG(procedural-world-generation)は、世界の端に陸が出てしまう問題がありました。生成クラスを直接動かして調べた結果、設定値の工夫・世界の向きの選択・上下を白い氷にするの3つで、ほぼ解決できることが分かりました。PWGは諦めず、下の使い方で使います。

1. 今後のPWGの使い方(決まり)

  1. 設定値「大陸の地殻の割合(continentalShare)」を、陸の割合(landFraction)と同じ値にする。陸は0.5前後・大陸は3つ(continentCount=[3,3])。
  2. たくさん作り(1個約20秒)、縁の8ピクセル幅の陸の割合を測る。
  3. 上下の端は白い氷にしてよいので、左右の端が海の世界を選ぶ。左右に陸があって上下が海なら、世界を90度回して使う。
  4. 描く前に、陸の割合と端を必ず実測する(基準外は使わない)。

2. 検証の方法

PWGの生成クラス(Pipeline)を、ブラウザなしで直接動かしました(ブラウザ経由は約90秒、直接は約20秒)。設定値をわたして世界を作り、標高と水の種類のデータから、陸の割合と四辺それぞれの端の陸の割合を数えました(端=縁の8ピクセル幅)。道具: mapstyle/tools/pwg_edge_probe.ts(PWG側のmetricsフォルダに置いて動かす)。

実行の例: node --experimental-transform-types --no-warnings --import ./metrics/register.mjs metrics/edge_probe.ts 7 '{"landFraction":0.5,"continentCount":[3,3],"continentalShare":0.5}'

4. 効かなかったこと(クラスの中を変えた試し)

PWGのコードには、大陸が地図の端に伸びにくくする仕組みがあります(端に近いほど育ちにくくする)。その強さと範囲を強めて試しましたが、端の陸はむしろ増えました(最大100%の世界も出た)。端の問題の原因は、そこではありません。コードは元に戻してあります。

5. 限界・未確認

  • 端の陸が5%以下という数字だけで選んだ。絵は見ていない。16個のうち使えるものの見た目は未確認。
  • 設定値は陸5割の1通りだけ。陸4割・6割では確かめていない。
  • 世界は正方形(1024×1024)。1400×900の地図に置くと、左右に海が余り、画像全体の陸は約0.65倍になる(陸5割で約3割)。陸4〜6割の基準に合わせる対策(横に引き伸ばす、陸を増やすなど)は未検証。
  • 氷にする部分の見た目(白の置き方)は未作成。
