Worldsmith — procedural fantasy map and terrain generator

Worldsmith generates infinite fantasy world maps in your browser from a numeric seed. Terrain uses domain-warped fractal noise with ridged mountain ranges; biomes are derived by crossing elevation, moisture and temperature; rivers are computed with D8 flow accumulation so tributaries merge into real drainage networks; and regions are given procedurally generated names. Maps can be exported as PNG images up to poster size, as editable SVG, as world data in JSON, and as 8-bit or 16-bit heightmaps suitable for terrain import into Unity, Unreal Engine, Blender and World Machine. It is free, open source under the MIT license, and runs entirely client-side with no account, no server and no dependencies.
