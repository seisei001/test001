地図ソフトを見る

概要: 検証に使った3つの地図ソフトを、ここで実際に動かせます。どれも MIT ライセンスの公開ソフトで、そのまま置いています(Azgaar のみ、解析用の外部通信を外しました)。

Azgaar(国・川・道まで作る)

国・国境・国名・川・道・街・経済まで持つ。立体表示あり。重め(最初の読み込みで約3MB、世界づくりに約2秒)。左上の「▶」で設定、画面右下の「?」でヘルプ。立体は設定の「3D」から。 開く

procedural-world-generation(本格的な地形)

侵食・川・気候・生き物の分布まで作る、写実的な立体地形。世界ができるまで約30秒かかる(最初は「Build」の表示が出ます)。右上の「2D」で平面に切り替え。「Export」で標高画像を取り出せる。 開く

Worldsmith(軽くて速い)

軽く(約0.15MB)、すぐ世界ができる平面図。無限に広がる世界。山の陰影がきれい。「Export」から標高画像・SVG・データを取り出せる。(実在の地球の標高モードは、容量が大きいため外しています) 開く

それぞれのライセンス文は、各フォルダの LICENSE にあります。比較の結果は 3候補の比較、使い回しの結果は 地図の使い回し検証 にあります。
