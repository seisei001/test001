# AvatarSample_A.vrm / AvatarSample_B.vrm のライセンス

VRoid公式サンプル「AvatarSample_A」「AvatarSample_B」。npmパッケージ
`@v-idol/vidol-agent-sample-a` / `-b` 経由で取得。

VRMファイル内部に埋め込まれた公式メタデータで、いずれも以下を確認済み:

- `author`: VRoid Project
- 法人・個人とも商用利用可(`corporate_commercial_use=allow`, `personal_commercial_use=profit`)
- クレジット表記不要(`credit=unnecessary`)
- 改変・再配布可(`modification=allow`, `redistribution=allow`)

## 切り替え方法

`index.html` の `AVATAR_URL` 定数を書き換えるだけです。
