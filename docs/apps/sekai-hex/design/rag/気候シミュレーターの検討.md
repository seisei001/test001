## 今
- [案 11-28 06:01 ユーザー提案(質問「どうだろう?」)] 天候シミュレーターは、(a)正規計算とガウス揺らぎによるランダムの簡易的な計算方法と、(b)イベント発生時の完全計算版、の2つを作る。→ Claudeの読み: 通常=基本値(正規の計算)にガウス揺らぎを重ねた軽い計算/イベント時=その場所・その期間だけ完全計算。評価=合理的(気流・魔力の場と同じ揺らぎの手法・既存の頻度案と整合)。要点=簡易版が「イベントの発生」を決め、完全版は起きた所だけ計算し、結果を差分で地図データに書く。未決=イベントの発生条件・簡易版が基本値からずれすぎない上限。
- [案 11-28 05:59 ユーザー提案(質問「どう?」)] 気候シミュレーターの基本値は、最初に作るデータで計算する。とても重くなりそうなので初期値を作っておく。変更する時はターンの最後か10年ごと。→ Claudeの評価: 良い案。1ターン=1か月なので10年=120ターン(「六つの層」)。二段の頻度(軽い差分=ターン末/重い再計算=10年ごと)が合う。未決=何をどちらに入れるか・季節の扱い。
- [調査 11-28] 気候を作る入力と手順(公開の作例の共通点):
  1. 入力=緯度(基礎の気温の曲線)・標高(1km上がるごとに約6.5度下がる)・海の位置(水蒸気の元)・風の場。
  2. 気温=緯度の曲線−標高の分+小さなゆらぎ。
  3. 降水=海から蒸発→風に乗せて数十回に分けて運ぶ→気温に応じた割合で雨にする→山で空気が冷えて雨が増え、山の裏は乾く(雨陰)。陸の蒸発は無視して簡単にする。
  4. 作例は年平均だけ。季節・海流・気圧は後回し。作者の言葉「本物を計算するより、似せて作る方が制御できる」。
- [調査] 大気の動き: 半球ごとに3つの対流セル(計6帯)。自転の力(コリオリ)で地表の風は西→東が主。作例の限界=季節・軸の傾き・圧力が無く、緯度±60度付近で不連続。式は地球に合わせた目分量。
- [調査] WorldEngine(公開ソフト)の順: プレート→ゆらぎ→降水(緯度と雨陰)→侵食→湿度→透水性→生物群系(ホールドリッジ式)。
- [調査] 気候→土地の類推の基準:
  - ケッペン: 入力=月ごとの平均気温と降水量。A熱帯(最寒月18度以上)/B乾燥(年降水量が年平均気温から決まる基準を下回る。基準の半分未満=砂漠、半分〜基準=草原)/C温帯(最暖月10度以上・最寒月−3〜18度)/D冷帯(最暖月10度以上・最寒月−3度以下)/E極(最暖月10度未満。0度超=ツンドラ・以下=氷雪)。第2文字=雨の季節(f=年中・s=夏乾燥・w=冬乾燥)、第3文字=夏の暑さ。H=高地。限界=平均だけを見て極端な年・日照・風を無視。植生との一致は多くの地域で悪い。
  - ホイッタカー/ホールドリッジ: 年平均気温と年降水量の2つで生物群系を決める(より簡素)。
- 既存仕様との関係(11-28 05:49に更新): 旧仕様は「気候は誕生時に決め動かさない/天候は倍率と災害/気候帯は地図生成が持つ」(「シミュレーターの役割分担」「地図データの持ち主」)。気流カードは魔力の場(火=気温・水=降水・風=風力・地=収穫)を読む。→ 新しい気候シミュレーターが、どこに入り、魔力の場とどう組むかが未決。

- [論文 11-28] 読んだ論文(要約経由): North ら1981(エネルギー収支モデルの総説)/Frierson・Held ら2006(水だけ入れた簡易な地球全体の大気モデル)/Spiegel ら2008(陸と海の割合と熱容量)/Biasiotti ら2022(EOS-ESTM・系外惑星用の簡易気候)/Ziegler・Rehfeld2021(TransEBM・経度緯度の格子)/Willeit ら2022(CLIMBER-X・中間複雑度モデル)/Beck ら2018(ケッペン-ガイガーの1km地図)。
  1. 気候の根本はエネルギーの収支: 入る太陽光=出る赤外線。緯度の帯ごとに温度を決め、熱は暖かい所から冷たい所へ拡散のように運ぶ(最も簡単な形)。氷は光を反射するので「冷える→氷が増える→さらに冷える」の連鎖があり、同じ日射でも複数の安定状態(今の気候・氷が多い気候・全凍結)ができる。出る赤外線・反射率・輸送の係数は実測に合わせた当てはめで、雲はほぼ扱えない。
  2. 陸と海の違いの本質は熱容量: 海は熱をためるので変化が遅い。海70%の星は応答に約10年で季節変化が小さく、海10%なら約1年で季節の振れが大きい(大陸性と海洋性の根拠)。簡易な2次元モデルは、地表を海・陸・海氷・陸氷の4種に分け、熱容量・反射率・熱の運びやすさを種類ごとに変える。128×64の格子で1年を約1.5秒。ただし高さ(標高)も降水も持たない。
  3. 地球全体の大気を簡略にしても、水の循環(蒸発→風で運ぶ→凝結)を残すと、赤道の上昇気流と降水帯・亜熱帯の乾燥・中緯度の低気圧と降水域が自然に現れる。風を決める力は気圧・自転の力(コリオリ)・熱。
  4. 中間複雑度モデル(CLIMBER-X): 大気は経験式で、水蒸気を風で運ぶ(移流)+渦を拡散で表す。地表付近の相対湿度が95%を超えると降水。5度格子・1日刻みで、16CPUで1日に約1万年。天気・極端現象・年ごとの揺れは出さず、平均の気候だけ。今の地球に合わせてあるため、まったく違う気候では信頼が下がる。
  5. 気候→土地の分類(ケッペン-ガイガー、Beck 2018): 入力=月平均気温と月降水量。乾燥(B)を最初に判定(年降水量が「年平均気温と雨の季節」から決まる基準の10倍より少ない→乾燥。その半分未満=砂漠、以上=草原)。熱帯(A)は最寒月18度以上。温帯(C)と冷帯(D)は最暖月10度超で、最寒月0度が境。極(E)は最暖月10度以下。30クラス。駅の観測で80%一致。気候帯は植生と同じではない(植生は遅れ、CO2なども無視)。
  6. 階層(簡単→複雑): 緯度の1次元収支 → 陸海の2次元収支 → 中間複雑度(水蒸気の輸送つき) → 簡略な全球大気 → 本格の全球大気モデル。必要な目的に応じて段を選ぶ。
- [案・Claudeの理解] 設計の候補: 段階1=緯度の収支+陸海の熱容量で年平均と季節の振れ(気温)/段階2=風で水蒸気を運び、山で降らせて雨陰を作る(降水)/類推=月別の気温・降水からケッペン型で土地を決める。目的は地球の再現でなく、ファンタジー世界の「それらしい気候」。限界: 論文はどれも地球向けに当てはめた係数で、魔力の場を入れる方法は論文にない。
