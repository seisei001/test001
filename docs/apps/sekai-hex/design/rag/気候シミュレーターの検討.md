- [論文 11-28] 読んだ論文(要約経由): North ら1981(エネルギー収支モデルの総説)/Frierson・Held ら2006(水だけ入れた簡易な地球全体の大気モデル)/Spiegel ら2008(陸と海の割合と熱容量)/Biasiotti ら2022(EOS-ESTM・系外惑星用の簡易気候)/Ziegler・Rehfeld2021(TransEBM・経度緯度の格子)/Willeit ら2022(CLIMBER-X・中間複雑度モデル)/Beck ら2018(ケッペン-ガイガーの1km地図)。
  1. 気候の根本はエネルギーの収支: 入る太陽光=出る赤外線。緯度の帯ごとに温度を決め、熱は暖かい所から冷たい所へ拡散のように運ぶ(最も簡単な形)。氷は光を反射するので「冷える→氷が増える→さらに冷える」の連鎖があり、同じ日射でも複数の安定状態(今の気候・氷が多い気候・全凍結)ができる。出る赤外線・反射率・輸送の係数は実測に合わせた当てはめで、雲はほぼ扱えない。
  2. 陸と海の違いの本質は熱容量: 海は熱をためるので変化が遅い。海70%の星は応答に約10年で季節変化が小さく、海10%なら約1年で季節の振れが大きい(大陸性と海洋性の根拠)。簡易な2次元モデルは、地表を海・陸・海氷・陸氷の4種に分け、熱容量・反射率・熱の運びやすさを種類ごとに変える。128×64の格子で1年を約1.5秒。ただし高さ(標高)も降水も持たない。

  4. 中間複雑度モデル(CLIMBER-X): 大気は経験式で、水蒸気を風で運ぶ(移流)+渦を拡散で表す。地表付近の相対湿度が95%を超えると降水。5度格子・1日刻みで、16CPUで1日に約1万年。天気・極端現象・年ごとの揺れは出さず、平均の気候だけ。今の地球に合わせてあるため、まったく違う気候では信頼が下がる。
  5. 気候→土地の分類(ケッペン-ガイガー、Beck 2018): 入力=月平均気温と月降水量。乾燥(B)を最初に判定(年降水量が「年平均気温と雨の季節」から決まる基準の10倍より少ない→乾燥。その半分未満=砂漠、以上=草原)。熱帯(A)は最寒月18度以上。温帯(C)と冷帯(D)は最暖月10度超で、最寒月0度が境。極(E)は最暖月10度以下。30クラス。駅の観測で80%一致。気候帯は植生と同じではない(植生は遅れ、CO2なども無視)。
  6. 階層(簡単→複雑): 緯度の1次元収支 → 陸海の2次元収支 → 中間複雑度(水蒸気の輸送つき) → 簡略な全球大気 → 本格の全球大気モデル。必要な目的に応じて段を選ぶ。
