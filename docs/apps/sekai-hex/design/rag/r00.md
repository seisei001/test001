# 世界地図の作り方(最上位仕様)
検索語: 最上位仕様 世界地図 作り方 平坦な絵 ローポリ UV 塗り重ね 毎回ゼロ 芸術性 擬似の絵 小手先禁止 海岸線 水の高さ アンジュレーション
状態: 確定(ユーザー 11-23 22:57〜11-24 05:35)。他のどの規則・試作より上位。印: [確]ユーザー決定 [案]私の提案 [評]ユーザー評価 [ボツ]不採用 [置]置換済み

- [確] 毎回ゼロから。PWG起動〜全実装を一本のアプリ(mapstyle/tools/make_world.py)で。データは塗り替え。残す絵はユーザーが言う。
- [確] 地図データ=シミュレーター側の完全なデータ。見せる地図=そこから作るファンタジーらしい擬似の絵。今の作業=芸術性を上げる。完全さ(データとの一致)は求めない。海と陸の境は絵としては存在しない。
- [確] 順序 ①平坦な絵を先に描く ②ローポリを作る ③UVで貼る(一枚の絵に起伏を付ける方法)。ローポリの色と海岸線が二重に出ることはない。
- [確] 絵=一枚の平たい紙に下から上へ塗り重ね: 海陸の色の境→森・川→今後 街・城・特殊地形。森・林は平らに貼る。足す要素が起伏へ影響するかは未実装。
- [確] 海は平坦。海岸線=高さ0=ローポリの頂点。三角が緩ければ海へ出てよい。絵の縁は三角の中に普通に描く(ローポリへ絵を合わせない・切り抜かない)。
- [確] 水の高さ(海・湖・川の水面と底)=交通網・天候の仕事。地図は持たない。
- [確] 魔力量・地脈の場も地図データと同じ仕様(持ち主=地図データ側)。
- [確] 小手先の修正禁止。仕様どおり出来ない時は直さず報告。仕様に無ければ質問。作り方を無断で変えない。
- [ボツ] 私の解釈でユーザーの言葉でなかったもの: 縁の切り抜き(alpha)・輪郭へ頂点を足す・陸色で海側を埋める・海を透明にする・海底と海面を地図が同時に持つ。理由=仕様に無い作り方の変更。
- 未解決: 海岸の緩い三角の淡い尖り(完全は求めない範囲か判断待ち)。
