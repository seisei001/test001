# 魔法の在り方・異世界の定義・魔法の強さ
検索語: 異世界 ファンタジー 定義 魔法 異種族 柱 物理法則 斥力 引力 魔法の強さ 才能 種族 場所の魔力 絵本寄り リアリティ
状態: 一部確定。「異世界とは何か」の言葉での定義(項目⓪)は未決(協議中)

- [確 11-21] 異世界を決める柱=魔法の在り方と異種族の在り方。リアリティの方向=絵本寄り(記号・「そういう世界」で見せ、因果を細かく描かない)。
- [確] 魔法の在り方は物理法則に影響し、よって地形にも影響する。魔法が影響するもの=斥力と引力、自然現象の発生、地脈、固有の能力(生命力・治癒力・体力・技術力)。
- [確] 個人の魔法の強さへの影響力=才能8:種族3:場所の魔力2。「魔力の量」と「場所の魔力」は同じ(個人が持つ魔力量という別要素は無い)。場所の魔力=地脈・魔力の場(R13)。
- 斥力は浮島を作る(R17)。魔物の巣=R14。
- [調査 11-21] 異世界=現実との対比+転生・転移・召喚/ファンタジー=魔法・中世・和風中華・ハイ/ロー/魔法=科学・法則と対(共起集計 isekai1.html、日本語Wikipedia10記事。測定した類似度ではない)。
- [未決] ⓪の定義/人側(才能・種族・場所の魔力の計算)/魔導石/二段目(異世界応用の絵)は⓪が決まるまで着手しない約束(11-21)。
