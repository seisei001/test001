# 森・植生・特殊地形(設計と現行)
検索語: 森 木 植生 群系 28群系 広葉樹 針葉樹 木線 特殊地形 遺跡 ダンジョン 魔物の巣 砂漠 沼 第10版 forest_world_layer 二段方式
状態: 描き方=確定(第10版 評価「とても良い」)/設計3本柱=案(11-21)

- [確 描き方 第10版] 暗い緑の下地(形=ガウス揺らぎ+中心が高い丘、面積約40%、縁は不規則)→暗い層の木を70%(縁帯は約60%)→明るい層を下側へ(ガウス揺らぎで置く確率。全体目標22%)。広葉樹=丸い樹冠+上の明るい三日月(下の三日月は無し)・Gemini影絵9種・大きさ11〜24ランダム。針葉樹=2段の三角+光側の尖り三角。広葉樹と針葉樹は別々。評価軸は「明暗がある・大きさが少しランダム」。
- [確] 森は絵を平らに貼る(R00)。山頂・木線より上・山の強調域には生やさない。
- [確 11-21] 二段方式: ①地球の植生を土台に森を「塊」で描く(衛星画像の滲みは不可。丸と三角は良いが村〜戦場向き)②その後に異世界の上位概念を応用。
- [評 11-21] 前の木(mapstyle50)=杜撰(種類少・山頂にも木・砂漠沼遺跡無し・緑が多すぎ)。
- [案 6G 3本柱] ①地面も植生もPWG28群系で決める(12区分に寄せない)②木は群系×標高×湿り気で種類・密度・大きさ③特異地形(火山・カルデラ・台地・遺跡・地上ダンジョン・魔物の巣)は世界データの点(数十〜百数十)。PWG5の陸の分布は温帯偏り(広葉樹21%・ツンドラ9.7%…熱帯の林ほぼ0%)→世界設定で偏りを変えてよい(確 11-21)。
- 現行実装: 球体世界は簡易(群系の森に塊を置く・FM_FOREST_DMIN=0.08/SP=50・seed31で32塊)。6G設計(28群系・選んで強調)は未対応。
- [過去] 森を地図の水彩風に馴染ませる課題(色が濃く浮く)・FM_LP_OVERLAYで森の層をUV貼り(11-21 評価「良かった」)。
