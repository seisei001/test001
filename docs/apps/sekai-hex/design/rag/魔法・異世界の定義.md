# 魔法の在り方・異世界の定義・魔法の強さ

状態: 一部確定。「異世界とは何か」の言葉での定義(項目⓪)は未決(協議中)

## 今の確定
- [確 11-28 07:07 ユーザー・創作] 魔力に関わる存在は2種: 生物として成生(生まれ出る)する魔物と、世界の魔力を摂取して魔法を使う人間。魔力は魔力を持つ生物の魔力量と効果を増やす。魔力だまりは魔力を持つ生物の能力を極端に上げる。魔力災害の定義は「魔物・スタンピード」を参照。
- [確 11-21] 異世界を決める柱=魔法の在り方と異種族の在り方。リアリティの方向=絵本寄り(記号・「そういう世界」で見せ、因果を細かく描かない)。
- [確] 魔法の在り方は物理法則に影響し、よって地形にも影響する。魔法が影響するもの=斥力と引力、自然現象の発生、地脈、固有の能力(生命力・治癒力・体力・技術力)。
- [確] 個人の魔法の強さへの影響力=才能8:種族3:場所の魔力2。「魔力の量」と「場所の魔力」は同じ(個人が持つ魔力量という別要素は無い)。場所の魔力=地脈・魔力の場(「魔力・四元素・地脈」)。
- 斥力は浮島を作る(「浮島」)。魔物の巣=「魔物・スタンピード」。
