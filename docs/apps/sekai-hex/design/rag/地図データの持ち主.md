# 地図データの持ち主と範囲(何を地図が持ち、何を他が持つか)
検索語: 地図データ 持ち主 場所の種別 効率で振り分け 川 湖 水の高さ 交通網 天候 魔力 地脈 シミュレーター 読むだけ
状態: 確定(11-23 01:39〜01:46、11-24 05:30・05:35)

## 今
- [確] 地図データは要素を含めて作る(論点②)。ただし全部は持たない(非効率)。元々地図データで持った方がよいものは持たせ、他は持ち主のシミュレーターが持つ。
- [確] 地図データ=「その場が何か」(陸・海・川・湖)の簡単なデータ。深さ・流量・幅などの細部は持ち主が別に持つ。川は最初からデータで持たなくてよい(交通網が作り、「川」として地図へ戻す)。
- [確] 水の高さ(海・湖・川の水面と底)=交通網・天候。地図(絵+ローポリ)は持たない。
- [確] 魔力量・地脈の場=地図データ側が生成(毎回ゼロから、一本のアプリ、塗り替え)。交通網・天候・人口動態は読むだけ。
- 流れ(案): 標高・陸海→天候・交通網・地形/気候帯・肥沃度→経済・人口/川湖道港→経済・軍・地政学/山・海峡・自然国境→地政学・戦闘。原則=気候は誕生時に決め動かさない。上が下を縛る。
