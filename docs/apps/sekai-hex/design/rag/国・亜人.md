# 世界・国・亜人・降伏・承継・資源
検索語: 国 亜人 12国 湖の連邦 商業都市国家 降伏 承継 簒奪 分裂 勢力 資源 課税 辺境 割合 逆転
状態: 確定(11-14)。一部仮置き

## 今
- [確] 人間12国+湖の連邦+商業都市国家。亜人は国の種類でなく個人の能力。割合=住みやすい所(人口動態・経済が決める)を中央に最小2%、辺境ほど増える。70%超の地域は亜人の国(国土が大きく弱い。ロシアのよう)。辺境に拠点を約70%置く。逆転(辺境が栄える)も止めない
- [確] 初期の国境=地図データを時間ゼロの状態に使い、以後は人口動態・経済・戦争が動かす。国境の決め方(概念)=首都から費用の安い隣へ広げ先着。
- [確] 領主の課税権(ちょうど良い約4割)。輸送の目減りは割引率の表。ファンタジー要素(モンスター・生物兵器・魔術師・回復士・魔獣騎士・魔導具兵器)は決め打ちの表。魔道具には魔導石。
- 現行の球体世界の国=点で12分割した仮(極圏は国なし 「極の扱い」)。
