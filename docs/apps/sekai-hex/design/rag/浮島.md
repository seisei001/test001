# 浮島(斥力・層・大きさ・動き・絵)
検索語: 浮島 斥力 浮く 層 レベル 層替え 大きさ 上下運動 ローポリ 島 気流に乗る 地表の斥力 魔力の斥力 回廊
状態: 性質=確定(11-22)。数値は全て私の初期値(試作 koutyuuzu0.html)

- [確] 浮島は物の持つ斥力で浮く。ダウンフォースとは反発。動きは気流による。地表との斥力と魔力だまりの斥力で浮く(足し算)。地表が低く魔力が無い所は低い。
- [確 10:06] 山の斥力は上だけでなく横にも効く(山腹で避ける・山頂で押し上げ)。島どうしも斥力、気流の回廊から外れない力。
- [確] 島ごとに斥力の強弱・大きさの大小(0.6〜1.7倍/0.6〜1.5倍・独立)。斥力にレベルがあり、高く漂う島も低い島もあり、時々入れ替わる(層5段階:下端50/130/210/290/370、約25〜70秒ごとに層替え)。上下運動(揺れ・魔力の濃さ)で上下幅約400。
- [確] 世界地図にも表記する(11-23 22:15)。島の絵=8種(岩峰・遺跡・滝・森・鉱山・集落・水晶・城)の俯瞰・底面図から、手続きでローポリ+UV貼り(assets/islands/)。
- 浮島は「物の性質」であり場ではない(08:47)。航宙図は地表の高さと魔力の場を読むだけ。
- 実測(試作): 地面への食い込み0〜8歩、島の重なり0〜60歩、回廊の外にいる時間約55〜75%。島が世界に幾つあるか=数個(試作は5)。
- [未決/限界] 斥力が強いほど高く浮く物理関係は未実装(層は割り当て)/島の数・分布/「浮島(点データ)と斥力・引力の場」/iPhone未測定。
