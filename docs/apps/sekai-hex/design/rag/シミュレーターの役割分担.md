# シミュレーターの役割分担・生成順・移動手段
検索語: シミュレーター 役割 持ち主 地図生成 天候 交通網 経済 人口動態 地政学 軍 生成 実行 移動手段の表 ターン 全体の要
状態: 確定(OVERVIEW §3・4・5)。持ち主は1つに決める

## 今の確定
- 地図生成: 高さ・陸海・気候帯・肥沃度の初期値・地政学の足切り・「その場が何か」の種別(陸・海・川・湖)。魔力量・地脈の場も(「魔力・四元素・地脈」)。
- 天候: 雨・蒸発の倍率と災害(スタンピード含む)。気候そのものは動かさず、世界生成の設定を読む。季節=倍率、氷期等=数回の出来事(気候を動かすとパンクする 11-02)。
- 交通網=全体の要: 川・湖・水位・道・橋・港・運河・移動手段ごとの通行コスト。川湖の深さ・流量・幅の持ち主。作った川・湖の「種類」を地図データへ戻す。
- 経済: 食糧の収支(主役)・産業・交易。放置なら定常状態。交通網と厳密に相互関連。
- 人口動態: 人口の核と、イベント(戦争・飢饉・疫病・災害・移住・魔物)による増減だけ。ファンタジー制約は決め打ち設定。
- 地形の決定(人の手)・軍・街の規模・地政学(領主・国・郡・都市の木構造。戦略に含める)・軍の戦闘(戦域〜兵)。
- 表示は結果を読むだけ(川・道・街を独自に作らない)。変化は差分で積む。
- 移動手段=表の1行(地形別コスト・航続・速さ・積載・拠点・消費・天候の効き・設備)。徒歩/馬/舟/龍/飛空艇/航宙船/転移門。世界設定(剣と魔法/宇宙)は最初に使える手段の表で決まる。表の作成が次の工程。
## 今
- 生成順: 地図→(地脈)→交通網→経済→人口動態→地形→軍・街→調整→地政学。実行は毎ターン循環(上の制限→下が動く→集計が上へ)。
- 実装順(次): 移動手段の表→交通網→人口動態→経済→地政学→地形・軍・街→調整ループ。
