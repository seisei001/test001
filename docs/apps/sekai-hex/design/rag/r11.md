# 川・湖の絵の描き方(地図側)と水の持ち主
検索語: 川 湖 大河 河口 水色 光る 流域 water_layer 支流 合流 RIV_BASIN 湖の濃淡 水系 描き方
状態: 描き方=確定(ユーザー評価)/水の高さ=シミュレーター

- [確] 川は特徴的な大河だけ(数が多すぎる=11-22 22:01)。基準: PWG川の網(順位・流量・下流つき)で、流域の最大順位≥6(RIV_BASIN)の系統の、順位≥5を描く。seed31で川7,062画素。
- [確 形評価 11-22 21:25] PWGの川の網の形は良い。描き方の約束: 源流は山の中腹・支流が集まり下流ほど太い・合流は浅い角度・分かれず交差せず・必ず海か湖で終わる・雪山の上は消す。
- [確 色] 光る水色の芯+縁と所々に濃い青(水色一色は不可)。湖=中は青・外周に海と同じ薄い縁。小さい湖は目立たせず、大きい湖(400画素以上)だけ濃淡。
- 現行: 川・湖は一枚の平坦な絵に塗り重ねる(R00)。海へ入る河口の扇・蛇行(1画素未満)・滝は未。
- [ボツ] 川を地形の上に置く「帯(ribbons)」(絵と別実装)・流量の多い画素を拾う描き方(細切れ)。
- [確] 水の高さ・深さ・流量・幅=交通網・天候(R04)。水辺の魔力だまり=大都会(R14)は交通網の川湖データが要る。
