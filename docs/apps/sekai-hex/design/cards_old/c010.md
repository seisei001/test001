# カード10 世界・国・亜人 【確定(一部仮置き)】
検索語: 世界 国 亜人 12国 継承 降伏 資源
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 人間12国+湖の連邦+商業都市国家。亜人は国の種類ではなく個人の能力。割合は住みやすい所の中心が最小2%で辺境ほど増え、70%を超えた地域は亜人の国(国土が大きく弱い)。逆転も止めない。(11-14)
- 初期の国の境界は地図データを時間ゼロの状態として使い、あとは人口動態・経済・戦争のシミュレーターが動かす。
- 降伏・承継(子が継ぐ/簒奪/分裂して勢力になる)は仮置き。データは5種類(拠点・道・国・軍団・人物)、資源は5種(食糧・鉄・馬・塩・木材)。
