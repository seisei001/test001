# カード15 制作プロトコル(超基礎概念)と作業フロー 【確定(11-21)+案】
検索語: 制作プロトコル 超基礎概念 上位概念 下位概念 縛らない 影響 二段方式 ワークフロー CLAUDE.md 入口 作業フロー 木 植生 森の塊 地球の世界地図 異世界 応用 管理表
出典: 世界ハニカム 現行状態カード(2026-11-21)

- 適用範囲: このプロジェクト(ファンタジー世界戦争=世界ハニカム、docs/apps/fantasy-war と sekai-hex)だけ。他のアプリには適用しない。
- 【確定 11-21 ユーザー】超基礎概念: 上位概念は下位概念を縛らない(下位は自由に考えて、より良い物を作る)。ただし、上位が下位に影響するという当たり前の法則は無視しない。下位で分かったことが上位を変えさせることもある(変えるときは理由と日付を記録し、ユーザーに伝える)。上位が未確定のまま下位を積み上げない。
- 【確定 11-21 ユーザー】木・植生は二段方式。一段目=地球の世界地図: ①ファンタジー地図が植生をどう見せるかをネットで調べ、上位概念としてハブに書く ②森を「塊」でどう描くかを別コンセプトで追求(丸と三角は良いが村〜戦場の縮尺向き。衛星画像の滲みは不可)。二段目=異世界・ファンタジーの上位概念を取り入れた応用。管理表の項目: P0(入口の整備)→R0→R1→R2。
- 【確定 11-21 ユーザー】入口の置き場所: ルートの CLAUDE.md は道案内だけ(各アプリのフォルダに CLAUDE.md があれば最初に読む)。このプロジェクトの規則は docs/apps/fantasy-war/CLAUDE.md。パスは1つ。
- 【案】仕組み: CLAUDE.md はコンテキストであって強制ではなく、サブフォルダのものは、そのフォルダのファイルを読んだとき(起動時ではなく)に読まれる。確実に守らせる仕組み(hooks)は未導入。最後の歯止めはユーザーの確認。
- 運用: 作業前に管理表に項目を作り、終えたら状態・記録を更新。話題ごとにラグを検索。ユーザーの指示・評価はその場でSTATEに記録。詳細は docs/apps/fantasy-war/CLAUDE.md。
