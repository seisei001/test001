ローポリ建物 発注仕様書

概要:AIに「絵(テクスチャ)」と「形の数値データ(頂点・面・UV)」を一緒に作らせるための注文書です。 下で建物の種類を選ぶと、そのまま貼れる完結した注文文が出ます。返ってきた atlas.png と model.json をこちらに渡せば、街に置けます。

1. 注文文を作る

ボタンを押すと、その建物の注文文が丸ごとコピーされます。そのままGeminiやChatGPTに貼り、Tudorの展開図を添付してください。

2. 仕様の要点(注文文に全部入っています)

項目決めごと
座標単位メートル / 上が +Y / 玄関は +Z / 原点は建物中央の地面
形のデータ頂点の座標・UV(絵のどこを貼るか)・面の並び を数字の配列で
絵1024×1024 の1枚。どこに何を描くかを固定の割り付け表で指定(形とUVが必ず合う)
重さ三角形 300〜800 個
必須部品屋根の出・煙突(屋根を貫通)・庇や窓出っ張りなど、種類ごとに指定
自己検査AI自身に、個数・範囲・寸法を確認させ結果を報告させる
