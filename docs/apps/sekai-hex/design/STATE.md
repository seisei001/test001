## 世界地図の作り方(最上位仕様) 【確定 11-24 ユーザー。05:02・05:13・05:17 に私の解釈を訂正】
検索語: 最上位仕様 世界地図 作り方 平坦な絵 ローポリ UV アンジュレーション 海岸線 海底 海面 芸術性 毎回ゼロ 小手先禁止 不都合は報告

- 【確定】世界地図は**毎回ゼロから**作る。PWGの起動から全ての実装を、統一した一本のアプリ(mapstyle/tools/make_world.py)で行う。毎回のデータは塗り替える。残したい絵はユーザーが言う。
- 【確定】**地図データはシミュレーター側が持つ完全なデータ**。見せる地図は、そのデータから作る**擬似の絵**で、**ファンタジーらしく・芸術性を高める**ことが今の作業。**完全さ(データとの一致)は求めない**。海と陸の境は、絵としては存在しない(データから描いた擬似の表現)。
- 【確定】順序: **①平坦な絵を先に描く → ②ローポリを作る → ③UVで貼る**。「一枚の絵にアンジュレーション(起伏)をつける」付け方がローポリとUV。ローポリの色と海岸線が別々に同時に出ることはあり得ない。
- 【確定】海は平坦でよい。海岸線=高さ0の所で、ローポリではそこが頂点になる。三角が緩ければ海へ進出してよい。三角の中の絵の縁は、三角の中に普通に描かれる(ローポリに縁を合わせない・切り抜かない)。
- 【確定 11-24 05:30】最上位の世界地図=地図データ+絵とローポリ。**絵は詳細なデータを元に、仕様書(ハブ)の手順で描く**。描き方=**一枚の平たい紙に、下から上へ塗り重ねる**処理。最下層=海と陸の境で色が完全に変わる。その上に森、川。この塗り重ねで境の二重は消える。まだ足す予定=街・城・特殊な地形。足す要素がローポリの起伏に影響するかは**未実装**。森や林は絵を平らに貼る。
- 【確定 11-24 05:35 ユーザー】**魔力量と地脈の場も、地図データと同様の仕様**。生成の仕方はハブにある(ガウス揺らぎ・mana_vein2.py の標準設定・航宙図の場との上下の合計=「植生と特徴の設計」)。持ち主=地図データ側(毎回ゼロから・一本のアプリ・塗り替え)。交通網・天候・人口動態は読むだけ。

## 地面の色・縮尺・作法の検証【要点のみ】

- 緑・茶の細かい色は平均が世界の色に一致し集約する。砂漠・雪は季節・色調のずれで合わない。
- ファンタジー地図の作法(11-18調査): 白黒の起伏に約3割の薄い色の層、光は1方向、減色+ディザ、海は岸から離れるほど濃く、描く順は海岸線→山→川→森→飾り。
- 色彩加算は独立の最終処理(いつでも外せる)。世界5用のままで他は未評価。浅瀬の明るさは約27%を標準(11-19 ユーザー案)。
