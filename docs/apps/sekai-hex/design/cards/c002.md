# カード2 六つの層 【確定。第5層は11-17に変更】
検索語: 六層 層 世界 地方 戦域 戦場 俯瞰 兵の視点 百人隊 縮尺
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 設計上は六層: 1世界(約180km)/2地方(約16km)/3戦域(約1.4km)/4戦場(約127m)/5俯瞰/6兵の視点。(旧表は第5層=隊 約11m・3m俯瞰、第6層=兵 約1m)
- 2026-11-17 ユーザー判断: 第6層=兵一人の視点。第5層=その主人公の隊を高さ10mから斜めに俯瞰する層(百人隊=約100名)。主人公が五百人隊に昇進したらその隊に追随する。千人隊・五千人隊は戦場の層、一万人は戦域の層で見せるので層は増やさない。第5層は主人公や各隊の隊長をイベントで見せるための俯瞰図。
- 11-17 分類: 第1〜4層=「地図」として見せる。第5・6層=「ゲームの視線」の見せ方。
- 【未決】「ゲームの視線」と「操作はしない(眺めるだけ)」の整合。視点は主人公の目(第6層)と神の目(第1〜5層、イベント追随型)の2系統(11-14)。
- 【置換済み】「五層に統合/隊を内部の単位に格下げ」(11-17朝)→ 六層維持に訂正。「大隊約500名」→ 百人隊約100名に訂正。
