# カード9 人物・階級・昇進 
検索語: 人物 階級 昇進 百人隊 五百人隊 君主 能力 レベル 兵数
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 【確定】階級は兵数で決まる: 百人隊(百人隊長)→五百人隊→千人隊→五千人隊→軍(1万以上・将軍)→大将軍(5万以上を従える)→国/王(10万以上)→大国/大王(30万)→帝国/皇帝(50万)→大帝国/大帝(100万)。(POLICY §25.4)
- 【確定】君主のパラメータ: 能力8個(経済・人当たり・子を作る力・統率力・カリスマ・独創性・部下を見る目・教育力)+性格5個。戦略(国の運営)と戦術(戦場)は別のシミュレーター。戦略・戦術はカタログ方式(能力の閾値)。
- 【確定】レベルは見せる。素質×経験の割引からレベルを出す。主人公は素質が高く経験不足から始め、経験で成長する。奇跡特性(2%、主人公は必ず持つ。絶体絶命で20%補正)。群像劇(将軍・大臣・百人隊長たち)。人物は必要になったとき遅延生成。
- 【案 11-17】五百人隊長になる条件: ①実力(レベルが閾値以上。統率力・カリスマ中心)②功績(生き残り・勝利・部下の損耗の少なさ)③空きと元手(上の軍団に席があり、動員可能数から補充できる兵がある)。3つが揃ったとき昇進。数値は未定。
