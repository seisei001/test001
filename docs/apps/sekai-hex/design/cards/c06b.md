# カード6B 世界を作る基準と手順(世界を作る前に必ず読む) 【確定】
検索語: 世界を作る基準 陸の割合 大陸 端は海 PWG 端 陸 Azgaar 型 自作 簡易生成 Googleドライブ 保管 実測 作り直し 乱数 駄目になる 崩れる 基準外 大きなデータ 逸失防止
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 【確定 基準】陸の割合は4〜6割、大陸は3つほど、地図の端は海(参考の世界地図に合わせたユーザー判断 11-17)。描く前に実測し、基準外は作り直す。乱数のまま作って描かない。
- 【PWG】「地図の外=海」を指定しても端に陸が出ることがある(11-18 約10〜15%、11-20 陸の指定0.65〜0.75で陸42〜48%・端に陸12〜28%)。陸を増やすほど端に陸が出やすい。基準の両立は未達(進め方はユーザーと相談)。URLは ?seed= 形式(#の後は無効)。1個約90秒。pwg_convertは世界を正方形で縮めて左右を海で埋める。
- 【Azgaar】型の指定(continents・mediterraneanなど)で陸4〜5割・端は海になりやすい。細かさは2万点指定(export_az_template.cjs)。型指定なしの乱数は群島や山の少ない世界が混ざる(mapstyle35は基準外の参考)。
- 【自作の簡易生成】陸の割合は export_simple_param.py の環境変数 LF で指定(0.5で基準達成)。見た目検証用(川・自然境界の国・資源なし)。
- 【保管】世界データなど大きなデータはGoogleドライブ「ファンタジー世界戦争/世界データ」に保管する(1回の送信は約3MBまで)。保存済み: 8世界のzip(Drive直下)・新15世界(Azgaar5・PWG5・自作5)。未保存: PWG元データ28組(約39MB)。
- 【作業前の検索】話題ごとに project_search で関連カードを確かめてから作業する(カード14)。
