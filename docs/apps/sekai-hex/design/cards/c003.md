# カード3 地図の採用(AzgaarかPWGか) 【未決・留保】
検索語: 地図の採用 Azgaar PWG Worldsmith 自作 比較 評価 未決
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 候補4つ: Azgaar FMG / procedural-world-generation(PWG) / Worldsmith / 現アプリ(自作world.js)。いずれもMIT等で使える。
- 2026-11-17 ユーザー評価(素の標高を同じ3Dで比較): Azgaar=世界地図らしい。PWG=本物らしいが調整が必要そう。Worldsmith=ボツ。現アプリ=最初からデフォルメされていて良いが世界地図より地方・戦域向き。見た目の候補はAzgaarかPWGの二択。Worldsmithと現アプリは「見せ方に採用する地図」からは外す。
- 2026-11-17 PWGで3つの見せ方(立体・タップ360度・高低差の景色)を再現して見比べた結果: 見た目はAzgaarの方が良い印象。ただし理由が不明(PWGが劣るのか、見せ方がAzgaar向けだったのか)。→ 【採用は未決・留保】。
- 論点は「できた地図のうち、どれを見せ方に採用するか」だけ。大陸の数・陸の割合・気候の質・①形だけ/②要素まで・細部の分担は「あとで」。
- PWGの強み(参考): 詳細さ(細かい起伏)。ユーザー「詳細さが必要ならPWG」。Azgaarは詳細さが無いが世界地図らしい。
- 比較ページ: apps/fantasy-war/mapcheck4.html、apps/sekai-hex/design/mapcmp.html(素の標高を同じ3Dで比較)、tapworld-pwg.html、landscape-pwg.html。
