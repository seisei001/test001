# カード6 見せ方(世界の層) 【確定+未決】

- 【整理 11-23 22:18】世界の層で表記する地図は、球体PWG展開の一つだけ(11-23 22:15 ユーザー)。世界地図(3D)とその上に航宙図(3D)をセットで表記し、浮島は世界地図にも出す。航宙図は上下に並べるか表記を分けるかが未決。見せ方は今後協議して決める(カード17)。以下の古い記述(Azgaar前提・層ごとの出来事)は当時のもの。
- 【確定 11-17】世界の層は層を混ぜず一枚の立体地図にする。作りは「細かい標高の格子で面を盛り上げ、色と陰影の平面地図の絵を貼る」。現在の3D表示(細かい層の絵をぼかして混ぜる方式)はだめ。ハニカムの「少しずつ大きく見せる」仕組みは不要。データは変えず描画だけ新しくする。試作: design/world-still.html。
- 【確定 11-14】景色の方式: 遠景=円筒の絵3枚(360度)、近景=半径130の3D。世界地図をタップすると景色を360度見られる(試作 design/tapworld.html)。この方式は地図の元(Azgaar/PWG)に依存しない。
- 【確定 11-14】全部を3Dにしない。AI生成とBlenderは採らない。ゼルダのようにウェブで軽く綺麗に。ピンチ操作はやめる。
- 【未決 11-17】「違う見せ方」を考える。層ごとの「見せる出来事」はすべて未決(世界/地方/戦域/戦場/隊/兵)。見せ方のコンセプトの文も未完。実験候補: 絵巻風の景色(ユーザー発案)/光と霧/ジオラマ風の戦場。
