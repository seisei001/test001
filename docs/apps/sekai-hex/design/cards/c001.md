# カード1 目的と位置づけ 【確定】
検索語: 目的 ゲームではない 見せるシミュレーター 百人隊長 ウォーゲーム 完成の条件 芸術性
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 作るのはゲームではなく、物語を自動で作って見せる「見せるシミュレーター」。主題は「百人隊長から成り上がれるか」。主人公が死んだら終わり。(2026-11-05/14/15)
- ウォーゲーム。世界統一(他の勢力がすべて征服=滅亡か降伏)で終了。いつまでも統一されないのもあり。(11-14)
- 戦略シミュレーターのエンジンを積んだ、見て楽しめるアプリ。独創性は「見せ方」。(11-14)
- 操作はしない。眺めるだけ。何を見せるかはアプリ(見せ方担当のAI)が決める。(11-17)
- 六角形は必須ではない。既存の世界ハニカムは試作として残す。(11-14)
- 見る価値(芸術性)がなければ作る意味がない。完成の条件に「見る価値があるとユーザーが認めた」を入れた。(11-15)
