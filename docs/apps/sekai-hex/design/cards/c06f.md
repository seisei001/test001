# カード6F ファンタジー地図に足す要素 【案(11-20)】
検索語: ファンタジー地図 要素 足す 川 湖 方位記号 縮尺 地名 都市 森 国境 道 飾り 10秒の決まり レイヤー 優先順位
出典: 世界ハニカム 現行状態カード(2026-11-20)

- 資料: mapelements.html(ハブの過去調査・Tor・10秒の決まり)。いまの絵にあるのは羊皮紙・海岸の墨線・海の波線・山・枠と題名のみ。
- 優先1(データあり・安い): 川と湖(PWG=流量・湖あり、Azgaarもあり。湖は今は四角い淡い面になる癖を直す)、方位記号と縮尺、海の深さの色。優先2: 地名(順位を大きさで)、都市の記号、森(木の集まり)。優先3(シミュレーターができてから。嘘は描かない): 国境、道・橋。優先4: 飾り(海の怪物・船・札)。
- 方針案: 要素は別の透明な層(UV同位置の絵)にして足す(面は増やさない。入り切り可)。描く順は海岸線→山→川→森→都市→地名→飾り。10秒の決まり(主な地名を白黒でも10秒で見つける)で確かめる。優先順位はユーザー判断待ち。

- 【試作 11-20 ユーザー指示 海岸線の作り込み】整えた海岸線(データ形を保ちなめらか+ゆらぎ)で面のはみ出しを消し、切れない墨線(右下を太く)・浜・浅瀬・岸にそった波線5本(沖ほど間があき薄く)を足した(illus.py FM_COAST=2、mapstyle45)。出典: Fantastic Maps(海岸の描き方・4様式・昔風の海)。限界: 波線・浅瀬は控えめ、3D表示は未反映、内陸の四角い淡い面は未解決。
- 【試作 11-20 ユーザー指示 浅瀬が見えない】浅瀬を約27%→約80%・幅約2倍に強めた(mapstyle45に比較追記)。
- 【試作 11-20 ユーザー指示 次は川】PWGの流量・湖(pwg_dump_world.ts→pwg_rivers.py→illus.py FM_RIVER=1)で川と湖を重ねた(mapstyle46)。流量12以上だけ描く。限界: 目視のみ・四角い大湖は海扱いで未解決・3D未反映。
