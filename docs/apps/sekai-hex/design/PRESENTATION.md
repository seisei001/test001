# 見せ方の設計(2026-11-05 作り直し・たたき台)

主の目的(OVERVIEW §0)から出発する。これはゲームではなく、百人隊長から成り上がれるかを見るシミュレーター。画面は「見せ方担当のAI」が、出来事ごとに決める。

## 1. 失敗の整理
- 6層は縮み率の幾何から決まり、意味は後付けだった。
- 全層で同じ地形データと汎用の絵を使い回した。だから層が変わっても「同じ地図が拡大されただけ」か「突然別物」のどちらかになった。
- 絵柄と層の思想が連携していなかった。

## 2. 基本の考え方
1. **計算の層と、画面の場面を分ける。** 計算は今のまま、層ごとの担当が持つ。画面は「場面の種類」で決まり、層の数に縛られない。
2. **場面は「誰が主語の出来事か」で決まる。** 国、軍、会戦、百人隊、主人公。主語が変わると、見るべきもの、必要な情報、絵の言葉が変わる。
3. **同じものを使い回さない。** 山は、勢力図では記号、進軍図では絵地図の山、作戦図では地形の陰影、戦場では実景。地図の世界では当たり前の「一般化」(縮尺ごとに描き直す)をする。
4. **つながりは「主語と目印」で作る。** 追っている主語(例: 北方の軍→この百人隊→主人公)と、名前のついた目印(川、橋、砦)を場面をまたいで引き継ぐ。画面全体を拡大して見せない。
5. **降り方は出来事に紐づく。** 親の場面で該当の場所に枠を付け、その枠が子の場面に開く。経過は「帯」(北方国 › 国境地方 › 隘路 › 百人隊 › 主人公)で常に見せる。研究でも、縮尺の急変は迷いの原因で、間をつなぐと迷いが減ると報告されている。

## 3. 場面の種類と絵柄(案)
| 場面 | 主語 | 見せるもの | 絵柄 | 絵の状態 |
|---|---|---|---|---|
| 勢力図 | 国 | 国の塗り分け、国境、首都、街道、軍の旗、今回の出来事の印 | 羊皮紙の政略地図(平面、インクと淡彩) | 要(未作成) |
| 進軍図 | 軍 | 街道、街、補給線、行軍の縦隊、日数 | 鳥瞰の絵地図(山・森・街の絵) | あり(今の絵を流用可) |
| 作戦図 | 会戦 | 部隊の枠、向き、隘路・橋・高地、矢印 | 淡彩の作戦図(等高の陰影) | 要 |
| 戦場の場面 | 百人隊 | 隊列、地形の俯瞰、士気 | 45度俯瞰の彩色画 | 地面はあり、兵が要 |
| 場面絵 | 主人公 | 出来事の絵と文章(昇進、野営、死) | 挿絵 | 背景24枚あり、人物が要 |
| 年代記(地図ではない) | 世界 | 勢力変遷、主人公の経歴 | 紙面と章飾り | 要 |

場面の数は固定しない。出来事の洗い出しで増減する。

## 4. 汎用性のための絵の持ち方
- 地形×季節×時間帯の組み合わせで増やすのは「場面絵の背景」だけ。
- 国の見分けは、紋章と旗の組み合わせ規則で出す(絵の自作とするかは要判断)。
- 兵と人物は、役割(槍・弓・騎・旗手・隊長)と国色の2軸で組み替える。

## 5. 試作の範囲
1つの出来事「北の国境砦が落ち、百人隊が殿を務め、隊長が昇進する」を、5場面で通しに見せる(artifact)。絵が無い場面は枠とプロンプトで示す。了承後に積み上げる。

## 6. 縮尺の階段(2026-11-13 ユーザー指摘で追加)
世界地図の次に、いきなり軍や畑の絵が出た。これは誤り。地図は縮尺の階段を一段ずつ降りる。
- 世界 → **国(一つの国)** → **地方** → **都市** → 作戦図(戦場の地形)→ 戦場の場面 → 人物 → 年代記
- ものの大きさは、その地図の縮尺で決める。世界では街は点、国では小さな建物の絵、地方では町・村・砦が一つずつ、都市では家並みの区画。
- 同じ絵を拡大して使い回さない。縮尺ごとに専用の地図の絵を持つ。
- 各段で引き継ぐのは、主語と名前のついた目印(砦、川、橋、町)。
- 必要な絵(新規): 国の地図、地方の地図、都市の地図。
