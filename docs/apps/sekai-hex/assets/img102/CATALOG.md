## 使い方の優先順(提案)
1. 街・城・道・川(W04道/W05川/W06城/W01部品表)→ 見取り図と地形の参考、原画が来たら切り出して差し替え
2. 輸送具(T01〜T08)→ 輸送隊の表示。視点が6つあるので向きに合わせて選ぶ
3. 兵・魔物(C01〜C13, B01〜B04)→ 軍の表示。8方向の歩行コマを切り出す
4. 人々(P01,P02)→ 住民は描かない方針のため使わない

## 実用化に必要なこと
- 原画(大きい版)の入手
- 1品ずつ切り出し・背景透明化(scipyの輪郭フラッドフィル)
- 切り出し後に `assets/img102/cut/` へ置き、`sprites.js` の `timg` 系で読み込む

## 反映状況の追記(v0.54)
- 動物・海の生き物・船・怪物は、利用者が用意した大判の絵を1体ずつ切り出し `assets/animals/` に保存(切り出し道具 tools/cut_animals*.py)。生き物の呼び名→絵の対応表は sprites.js の AMAP。ここに無い生き物は描かない。
- 城は W06 の12タイルを `assets/world/K11〜K43` に切り出し、種(seed)で選ぶ。
- 絵が足りないもの: 城壁・街の門・市街地防壁・堀と橋・旗・塔・街タイプ別の大きい家・兵(白背景の1パーツずつの絵が望ましい)。
