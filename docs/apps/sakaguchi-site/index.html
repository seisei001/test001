神戸市 ・ 坂口誠税理士事務所

国税局37年の経験で、税務調査への「備え」を支える税理士

元・大阪国税局。税務調査、国際税務、システム監査の現場を知る税理士 坂口誠が、神戸から中小企業・公益法人の税務を支えます。

ご相談について経歴・強みを見る

この事務所の3つの強み

「国税の内側」「調査への備え」「システム・AI」が重なるところに、この事務所ならではの価値があります。

国税の内部構造を理解している

調査官の思考パターン、勘定科目の着眼点、資料の評価基準を熟知。国税内部のシステム・データ構造についても深い理解があります。

税務調査に強い

調査官が疑うポイントを事前に予測。証憑・仕訳・税務判断のつながりを整理し、調査対応を「型」にします。

システム・AIを実務に活かす

国税局で大型コンピュータのプログラマー・SEを経験。AIの仕組みも学び、将来的には条文ベースの検索など税務実務への応用を目指しています。
