# WorkMap - ワーク管理ツール(初期版)

タスクを親子ツリー(WBS)に分解して管理しつつ、カレンダー連携のタイムライン(ガントチャート)で依存関係とブロック状況を可視化する、個人〜小チーム向けの軽量なワーク管理Webアプリです。

ビルド不要の素のHTML/CSS/JavaScript + Node.js(Express) + JSONファイルストレージという最小構成にしており、データベースサーバーは不要です。

## 主な機能

- **タスク分解ツリー(WBS)**: 親タスク→子タスクへ何段階でも枝分かれさせて分解。展開/折りたたみ、進捗率は子タスクから自動集計。
- **タイムライン(ガントチャート)**: 月表示のカレンダーにタスクの期間をバー表示。
- **依存関係とブロック表示**: 「先行タスク」を設定すると、それが完了するまで後続タスクが着手できないことを鍵アイコン・矢印・斜線パターンで可視化。
- **担当者・ステータス管理**: 未着手/進行中/完了をワンクリックで切り替え。
- **簡易通知**: ヘッダーのベルアイコンに「期限が近いタスク」「ブロック中のタスク」を画面表示(メール・プッシュ通知は無し)。
- **簡易ログイン**: 共有パスワード+表示名によるシンプルな認証(個人〜小チーム向け)。

コメント・ファイル添付、外部カレンダー連携、通知メールなどは初期版では省略しています。

## 使い方

1. 依存パッケージをインストール

   ```bash
   cd work-management
   npm install
   ```

2. サーバーを起動

   ```bash
   npm start
   ```

3. ブラウザで `http://localhost:3100` を開く(自動的に `login.html` へ)

4. 表示名とパスワードでログイン。パスワードの初期値は `work1234`(環境変数 `WM_PASSWORD` で変更可能)

   ```bash
   WM_PASSWORD=your-password npm start
   ```

5. 初回起動時にサンプルプロジェクト「Webサイトリニューアル」が自動生成されます

## 無料でWebに公開する(Render)

Renderの無料プランを使うと、アカウント登録だけで恒久的な公開URLを取得できます(登録作業はご自身のGitHubアカウントで行ってください)。

1. https://render.com を開き、「Get Started」→ **GitHubアカウントでサインアップ**(無料・クレジットカード登録不要)
2. ログイン後、ダッシュボードで **「New +」→「Blueprint」** を選択
3. このリポジトリ(`seisei001/test001`)を接続すると、リポジトリ直下の `render.yaml` が自動検出されます(サービス名 `workmap`、無料プラン、`work-management` フォルダを対象に設定済み)
4. `WM_PASSWORD` の環境変数入力を求められるので、ログイン用パスワードを好きな文字列で設定
5. 「Apply」を押すとビルド・デプロイが始まり、数分後に `https://workmap-xxxx.onrender.com` のようなURLが発行されます

**無料プランの制約(ご注意ください)**
- 15分間アクセスが無いとサーバーがスリープし、次のアクセス時に起動まで30〜50秒ほどかかります
- 無料プランには永続ディスクが無いため、`work-management/data/store.json` のタスクデータは**再デプロイのたびにリセット**されます(サーバーの自動スリープ/復帰だけでは消えません)。長期的にデータを保持したい場合は、将来的に無料の外部データベース(Supabase等)への切り替えが必要です

## 仕組み

- データは `work-management/data/store.json` にJSON形式で保存されます(サーバー起動時に自動生成)。バックアップしたい場合はこのファイルをコピーしてください。
- 進捗率・ブロック状態は保存時ではなく、APIが返す際に依存関係とタスク構造からその都度計算しています。
- 認証はサーバー再起動でトークンがリセットされる簡易方式です。本格的なチーム利用には向きません。
